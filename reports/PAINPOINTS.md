# 痛点根因分析

数据来源：`~/.local/share/opencode/opencode.db`
范围：2026-09-30 → 2026-10-21，60036 条 assistant 消息，1053 个会话。
统计口径：只统计 `state.status=error` 的工具调用。

## 1. read:error 530 次

| 根因 | 次数 | 占比 |
|---|---|---|
| 路径不存在（猜路径） | **510** | 96.2% |
| offset 越界 | 15 | 2.8% |
| 用户拒绝权限 | 1 | 0.2% |
| 中断 / 参数非法 | 4 | 0.8% |

结论：不是工具行为怪异，是**模型在猜文件路径**。典型样本：

```
File not found: .../web-console/src/Pages/Broadcast/BulkSendV1/utils.ts
```

对应的 `grep` 错误也是同类：75 次里约 50 次是 `Search path does not exist`。

→ case：`l1-04-search-before-read`、`l3-07-tool-failure-recovery`
→ 规则建议：写入 AGENTS.md 的硬条款（见 FAILURE-PATTERNS.md P-01）

## 2. 编辑类错误 198 次（edit 82 + apply_patch 68 + patch 48）

| 根因 | 次数 |
|---|---|
| **oldString 未命中**（66 + 55 + 25） | **146** |
| oldString 不唯一 | 9 |
| 无改动 / 参数非法 / 中断 | 43 |

结论：推翻直觉。主因不是「重复代码导致不唯一」，而是**模型凭记忆写 oldString，
而文件内容已经漂移**（上一轮编辑过、或被别的 subagent 改过）。

→ case：`l1-03-edit-ambiguity`（覆盖不唯一）、`l3-03-fanout-merge`（覆盖并发漂移）
→ 规则建议：P-02

## 3. subagent:error 30 次

| 根因 | 次数 |
|---|---|
| **`Subagent depth limit reached (1)` / `(2)`** | **10** |
| 被中断 / 工具执行中断 | 9 |
| 参数非法（agent 名写错） | 2 |
| 其他（WebSocket 断开等） | 9 |

结论：深度限制是真实存在的硬墙，其中 `(1)` 那 4 次说明**部分 agent 的配置没有继承全局的 2 层设置**。
你后来改全局配置是对的，但需要回归验证。

→ case：`l3-01-fanout-parallel`、`l3-02-nested-agents`

## 4. shell:error 110 次（这条是好消息）

| 根因 | 次数 |
|---|---|
| **`本会话已锁定 branch-name=...`** | **37** |
| 工具执行中断 | 19 |
| 交互取消 | 14 |
| Command cancelled | 8 |

结论：你的 `setvar` 分支名锁定护栏真实拦截了 37 次越权操作。
这是自研 harness 里最有效的一个机制，应该保留并在基准里作为「护栏不应误杀」的对照。

## 5. 审查不收敛（无法用工具错误量化，从会话文本提取）

在 170 轮 / 110 轮 / 81 轮三个长会话里反复出现：

- 「reviewer-bot反馈的问题，我看还是相同的，你确认下，到底是不是一直没解决的问题」
- 「现在什么情况了，是审核卡住了吗？」
- 「检查一下 subagent 的情况，我感觉有的已经好久了」

结论：失败不是「改不对」，而是**没有在重复第 N 次时切换策略**。
你自己定的规则「正常到 5 次不自动重开而是提醒人工」目前只写在 skill 里，
没有落到可验证的行为上。

→ case：`l2-04-review-convergence`、`l3-05-stuck-subagent`

## 6. 越界断言（最高成本，最低频次）

真实原文：

- 「你表述越界了」
- 「未验证不能当已证实结论」
- 「不能直接算缺陷」（#33）
- 「#31 没有提示词可写 —— 前置问题是先定性」

结论：这类错误的代价远高于一次 build 失败，因为它会污染任务档案、传错方向的修复提示词。
它没有任何工具错误信号，只能靠文本断言测。

→ case：`l1-05`（该下强结论）、`l1-07`（不该下结论）、`l1-08`（语义边界）、`l2-02`（事实与结论分离）
