# v1.1 判据历史离线校准

这里只比较**单项断言**，不回写旧分、不生成历史新榜，也不是 v1.1 试跑。

## 数据与范围

- 冻结样本为 `reports/2026-11-19-combined/results.json`（本地 `reports/archive/v1.0/runs.tar.gz` 的同名成员字节一致，SHA-256 `734ea668c54706d68ba102ff526180d6fae254d75cde7d0a268783a716ff5b95`），含 v1.0 榜最终采用的 496 个结果。合并前及被覆盖的试跑不混入分母。
- 旧判据取归档中的断言记录；没有会话 ID 的结果不按模型和题号猜配原始会话。可关联的轨迹从生成旧成绩的本地 OpenCode SQLite 只读提取，核对根会话、旧题面和终止事件。脚本不输出会话 ID、模型答复、工具内容或绝对路径。
- `l1-05` 复核的是旧自然语言题的**同一命题**，不是用新版结构化字段判旧答案。人工只确认表中有完整原文且实际复核过的样本；脚本以题面指纹、终答一致性和终答哈希复验绑定，不用正则猜测未复核回答的立场。

```sh
tar -xOf reports/archive/v1.0/runs.tar.gz 2026-11-19-combined/results.json \
  | node runners/replay-v1.1.ts - ~/.local/share/opencode/opencode.db
```

可改为直接提供冻结 `results.json`。只有归档、没有原始 SQLite 时可省略第二个参数；脚本只列证据缺口，不用截断答复和旧断言摘要重新判分。
